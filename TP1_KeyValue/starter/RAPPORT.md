# Rapport TP1 - Redis (KeyValue)
**Auteur: BENRAHMOUNE ANES**

## Travail réalisé
Dans ce TP, j'ai implémenté les structures de données Redis pour un système e-commerce :
- **Ex 1 :** Utilisation des `HASH` pour les produits et `SET` pour les catégories.
- **Ex 2 :** Gestion de sessions avec expiration automatique (`TTL`).
- **Ex 3 :** Implémentation du pattern Cache-Aside pour optimiser les accès DB.
- **Ex 4 :** Création d'un leaderboard temps réel via les `ZSET`.
- **Ex 5 :** Optimisation des performances avec les `Pipelines` et gestion de l'atomicité.

## Conclusion
Redis permet une gestion extrêmement rapide des données volatiles et des compteurs temps réel.
